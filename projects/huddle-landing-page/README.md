# Huddle-style multi-section landing page

0xVerse Academy original teaching scaffold, using HTML, CSS, vanilla JavaScript and original SVG art.
Run via VS Code Live Server, as section fragments load with fetch().

Challenge inspiration: Frontend Mentor — Huddle landing page with alternating feature blocks.
Find the official challenge through https://www.frontendmentor.io/challenges.
Design assets and starter code from Frontend Mentor are not distributed here. Obtain permission for commercial course use.

Work areas:
- Header/nav: sections/header.html + styles/header.css
- Hero: sections/hero.html + styles/hero.css
- Grow Together / Flowing Conversations / Your Users: their matching HTML sections and styles/features.css
- CTA & Footer: sections/cta.html + sections/footer.html + styles/cta-footer.css
- Tutor-owned integration: index.html, script.js, style.css

Students should create separate feature branches and pull requests. Ask the tutor before editing shared styles.
