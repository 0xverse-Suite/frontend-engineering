RULES
1. Start a new feature branch from updated main after the setup pull request is merged.
2. Work only in the assigned files. Never overwrite another person's files.
3. Tutor owns index.html, style.css, script.js and shared base CSS.
4. Use desktop 1440px and mobile 375px designs; test intermediate widths too.
5. Run via VS Code Live Server when HTML sections are loaded using fetch.
6. Push commits, open a pull request to main, include screenshots and testing evidence.
7. Tutor reviews and merges. Everyone fetches/merges origin/main into their own branches.
8. The included references and illustrations are original class designs, not Frontend Mentor's downloadable official designs.

SUBMISSION
One pull request, two screenshots, a short list of files changed, and a paragraph explaining Git operations used.
