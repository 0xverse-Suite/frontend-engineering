# Frontend Engineering — Classroom Projects

One repository, separate project folders. Every project uses HTML, CSS and vanilla JavaScript (no frameworks).

| Project | Learning focus | Status |
| --- | --- | --- |
| manage-landing-page/ | Git collaboration, six separate components | Existing classroom project; do not overwrite student work |
| huddle-landing-page/ | Multiple page sections, Flexbox, responsiveness, team branches | New independently written scaffold |
| faq-accordion/ | DOM events, keyboard access, ARIA state | New independently written scaffold |
| loopstudios-landing-page/ | CSS Grid, image galleries, mobile navigation | New independently written scaffold |

These extra scaffolds have ORIGINAL SVG illustration resources and are inspired by public Frontend Mentor challenge descriptions. They do not contain Frontend Mentor's proprietary starter code or design files. For Frontend Mentor design/starter assets in commercial classes, contact them for permission.

Students: clone the repository, work within an assigned project folder, create a new feature branch per task, and submit a PR to main for tutor review.
