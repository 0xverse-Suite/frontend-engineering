# Frontend Engineering

Public course workspace for frontend assignments, exercises, examples, team projects, and portfolio-ready web applications.

**Course Lead:** To be assigned  
**Tutor team:** `@0xverse-Suite/frontend-tutors`  
**Student course team:** `@0xverse-Suite/frontend`

## Structure

- `assignments/` — briefs and acceptance criteria
- `exercises/` — focused practice
- `examples/` — tutor-maintained demonstrations
- `projects/` — reviewed individual and team applications
- `docs/` — course and setup documentation

Students work from an assigned Issue on `feature/<github-username-or-team>/<task>`, submit a pull request, respond to tutor feedback, and merge only after approval. Never commit credentials or personal records. Completed public work may be linked from a personal portfolio; see [STUDENT_GITHUB_GUIDE.md](STUDENT_GITHUB_GUIDE.md).

For unclear requirements or sensitive material, contact the course tutor team through the Issue before publishing.
